# 브랜드 — 사르르 · 르르

> 담당: R5. 팀 시안: `docs/design/reference/team_mockup.png`. 원본 그림: `docs/design/reference/ruru_master.png`. 그리는 규칙은 `docs/06_DESIGN_SYSTEM.md` 8절이 원본이다.

## 1. 이름
| | 정한 것 | 뜻 |
|---|---|---|
| 앱 | **사르르** (영문 Sareureu) | '사르르 녹다'. 숏폼에 시간이 소리 없이 녹아 버리는 느낌, 그리고 그걸 부드럽게 알려 주는 말투 |
| 캐릭터 | **르르** | 사르르에서 온 짝 이름. 각설탕 한 개 |
| 태그라인 | 숏폼에 녹아든 시간, 말 걸어 주는 친구 | 앱 소개·스토어 첫 줄 |
| 보조 문구 | 시간은 흐르고, 르르는 말을 걸어 | 브랜드 시트·발표 표지 |

- 문장에 넣기: "사르르 켜 놨어", "르르가 말 걸었어", "르르한테 물어봤어". 받침이 없어서 조사는 **가·는·를·랑·에게**.
- 영문은 Revised Romanization 표기 `Sareureu`. 영어권 발음이 어렵지만 국내 대상 캡스톤이라 문제 삼지 않는다. 해외 출시를 하면 다시 정한다.
- 코드에는 브랜드 이름을 쓰지 않는다(`com.capstone.pause`, `Pause*`, `Buddy*`). 이름이 또 바뀌어도 문자열·아이콘·그림만 고친다.

## 2. 르르는 어떤 친구인가
- **무엇**: 오늘 숏폼을 본 시간만큼 조금씩 녹는 각설탕. 새벽 4시면 새 각설탕으로 돌아온다.
- **왜 각설탕인가**: 숏폼은 설탕 같다. 달고 잠깐 좋지만, 모르는 사이에 많이 먹는다. 르르는 "그만 먹어"라고 혼내는 대신 "벌써 이만큼 녹았네"라고 같이 본다.
- **성격**: 눈치 빠르고 느긋한 친구. 잔소리는 하지만 훈계·수치심·진단(중독 등)은 없다. 내가 멈추면 누구보다 기뻐한다.
- **하지 않는 것**: 녹아서 아파하거나 울지 않는다. 사용자를 탓하지 않는다. 숫자를 지어내지 않는다(숫자는 앱이 센다).

## 3. 말투
| 규칙 | 좋은 예 | 나쁜 예 |
|---|---|---|
| 반말, 한두 문장 | "한 편만 더가 벌써 {min}분이네. 계속 볼지, 잠깐 쉴지 골라 봐." | "사용자님, 시청 시간이 기준을 초과했습니다." |
| 선택권을 준다 | "오늘은 침대 가기 전에 답장 마무리해 볼까?" | "지금 당장 꺼." |
| 사실은 근거와 함께 | "이번 주 자기 전에는 메신저에서 넘어온 날이 많았어." | "넌 원래 의지가 약해서 그래." |
| 놀려도 비하하지 않는다 | "오늘 {app} 좀 재밌었나 보네. 잠깐 딴 거 하고 와도 돼." | "또 쇼츠야? 한심하다." |
| 이모지 최대 1개, 숫자는 자리표시자만 | "{min}분째야 🍬" | "37분째야!!! 😱😱" |

금지 표현 목록의 원본은 `docs/05_AI_SPEC.md` 7절 `BannedWords`다(중독·장애·진단·한심 등 + 외모·연애·성적 소재). 여기에 따로 적지 않는다.
- **녹은 정도를 문장으로 말하지 않는다.** "반쯤 녹았네" 같은 말은 AI가 지어내면 그림과 어긋난다. 녹은 단계는 그림으로만 보여 주고, 꼭 말해야 하면 코드가 `MeltStage`에 맞춘 고정 문장을 고른다.

## 4. 보이는 모습
- **워드마크(확정, 2026-11-05)**: 팀이 만든 로고 시안 3개 중 **1번**(둥글고 획이 살짝 물결치는 글자). 획이 사르르 녹아 흐르는 느낌이라 르르와 짝이 맞고, 일반 단어인 '사르르'를 상표로 지키려면 이렇게 개성 있는 글자 모양이 유리하다. 밑줄은 넣지 않는다.
  - 파일: `docs/brand/logo/`(SVG 라이트·다크, PNG 검정·흰색, 원본 `source_option1.png`), 앱 안은 벡터 `core/designsystem/src/main/res/drawable/designsystem_wordmark.xml`.
  - 색: 라이트 `#141416`, 다크 `#F2F2EC`. 라임·그라데이션·그림자를 입히지 않는다.
  - 크기: 상단 바 높이 22dp, **최소 18dp**(그보다 작으면 'ㄹ' 안쪽 틈이 막힌다). 둘레 여백은 글자 높이의 1/4 이상.
  - 앱 안에서 글꼴로 '사르르'를 다시 쳐서 로고처럼 쓰지 않는다. 문장 안의 이름은 그냥 글자(`R.string.app_name`).
- **색**: 바탕 `#F3F3EE`(라이트)·`#0E0E11`(다크), 잉크 `#141416`, 포인트 라임 `#C6F24E`. 르르의 흰색은 색 토큰이 아니라 그림 자체의 색이다. 밝은 바탕에서는 그림자를 꼭 넣는다.
- **르르 크기·표정·녹는 단계**: 06 문서 8절.
- **앱 아이콘**: 라임 바탕 + 르르(기본 얼굴). 안드로이드 적응형 아이콘에는 다크 버전이 없고 테마 아이콘(monochrome = 실루엣)만 있다. `#0E0E11` 바탕 아이콘은 스토어·발표 이미지용.
