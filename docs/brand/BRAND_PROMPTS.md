# 르르 그림 더 만들기 (한 번에 복사)

르르는 **몸 그림 한 장 + 코드로 그린 얼굴**이다(06 문서 8절). 그래서 표정 그림은 만들지 않는다. 더 만들 그림은 4장이다: 얼굴 없는 고해상도 원본, 녹는 단계 3장. 앱 아이콘은 이 그림으로 코드가 만든다.

**쓰는 법**
1. 이미지를 만들 수 있는 대화형 AI(ChatGPT, Gemini 등)에 `docs/design/reference/ruru_master.png`를 첨부하고, 아래 블록 전체를 붙여 넣는다.
2. 받은 그림을 `docs/design/reference/`에 `ruru_body_hi.png`, `ruru_melt_1.png`~`ruru_melt_3.png`로 저장한다.
3. 배경을 지우고 크기를 맞춘다.
   ```
   python3 docs/brand/tools/cutout.py docs/design/reference/ruru_melt_1.png core/designsystem/src/main/res/drawable-nodpi/designsystem_buddy_melt_1.webp
   ```
   필요한 패키지는 `pip install opencv-python-headless pillow numpy`.
4. 새 몸 그림으로 바꿨다면 얼굴 기준점 A를 다시 잰다. 지금 그림에서는 **그림 전체를 0~100으로 볼 때 (39.7, 78.0)** 이다(각설탕 앞면 아래쪽, 왼쪽에 가까운 자리). 결과 그림을 `BuddyAvatar` 미리보기에서 6표정 × 28/56/72dp로 확인한다.
5. 네 장이 서로 같은 각설탕처럼 보이지 않으면 그 장만 다시 만든다. "1번 그림과 설탕 알갱이 크기·조명·각도를 똑같이 맞춰서 다시"라고 말하면 된다.

```
첨부한 그림은 우리 앱 캐릭터 '르르'의 원본이야. 작은 얼굴이 있는 각설탕 한 개고, 오른쪽 아래에 녹은 설탕 웅덩이가 조금 있어.
이 각설탕과 완전히 같은 물체로 그림 4장을 차례로 만들어 줘. 중간에 묻지 말고 4장을 끝까지 만들어.

[4장 모두 지킬 것]
- 같은 각설탕: 모양·크기·비율, 설탕 알갱이의 크기와 반짝임, 조명 방향(왼쪽 위), 카메라 각도(정면에서 약간 오른쪽 위, 3/4 시점)를 원본과 똑같이.
- 얼굴을 그리지 마. 눈·입·표정이 전혀 없어야 해(얼굴은 앱이 코드로 따로 그린다).
- 손·발·팔·소품·글자·로고·워터마크 없음. 각설탕 한 개만.
- 배경: 투명 PNG가 되면 투명으로. 안 되면 원본과 같은 단색 회청색(#97AAB6), 그라데이션·무늬 없이. 바닥에는 옅은 접지 그림자만.
- 각설탕이 그림 가운데, 둘레 여백 10% 이상. 정사각형 1024×1024.
- 사진처럼 사실적인 제품 사진 느낌(원본과 같은 질감). 만화풍·3D 장난감 느낌으로 바꾸지 마.
- 녹는 모습은 귀엽고 차분하게. 무섭거나, 아파 보이거나, 지저분하거나, 끈적하게 흘러내리는 공포 느낌은 안 돼.

[1번 · 고해상도 원본]
원본과 똑같은 각설탕, 얼굴만 없고 오른쪽 아래 작은 웅덩이는 그대로.

[2번 · 녹는 단계 1 — 조금 녹음]
아래 모서리가 아주 살짝 둥글어지고, 바닥 둘레에 얇고 투명한 설탕물 웅덩이가 각설탕 폭의 60% 정도로 퍼짐. 높이는 그대로.

[3번 · 녹는 단계 2 — 꽤 녹음]
아래쪽 1/4이 부드럽게 녹아 퍼지고, 웅덩이가 각설탕 폭의 80% 정도. 전체 높이는 원본의 90% 정도. 위쪽 모서리와 윗면은 아직 또렷한 각설탕.

[4번 · 녹는 단계 3 — 많이 녹음(최대)]
아랫부분이 넓게 퍼져 살짝 주저앉은 모양, 높이는 원본의 80% 정도. 웅덩이가 각설탕 폭보다 조금 넓음. 그래도 위에서 보면 분명히 각설탕(윗면의 네모가 보임). 무너지거나 쪼개지지 않음.

다 만들면 4장이 같은 각설탕인지 스스로 비교해 보고, 다른 장이 있으면 그 장만 다시 만들어 줘.
```

## 앱 아이콘·알림 아이콘은 그리지 않는다
- 앱 아이콘: 배경 `#C6F24E` + 몸 그림 + 기본 얼굴을 코드(`BuddyBitmap`)로 구워 만든다. 적응형 아이콘에는 다크 버전이 없고 테마 아이콘은 monochrome 레이어(실루엣)로 처리된다. `#0E0E11` 바탕은 스토어·발표 이미지에만 쓴다. 시안에서 고른 워드마크(사르르 + 라임 밑줄)는 아이콘에 넣지 않는다(작은 크기에서 글자는 안 읽힌다).
- 알림 작은 아이콘·monochrome 레이어: `core/designsystem/src/main/res/drawable/designsystem_ic_buddy_silhouette.xml`(단색 벡터). 안드로이드는 알림 작은 아이콘을 단색으로만 그린다.

## 저작권 메모
AI가 기계적으로 만든 그림 자체는 저작물로 인정되지 않는다. 사람이 고르고, 고치고, 배열한 부분만 등록할 수 있다(문화체육관광부·한국저작권위원회, 생성형 AI 저작권 등록·분쟁 예방 안내서, 2025). 그래서 르르를 지키는 방법은 **이름·로고 상표 출원**과 **제작 기록 보관**(프롬프트, 고른 이유, 손본 내역)이다. 쓰는 이미지 생성 서비스의 상업적 이용 약관도 확인한다. 자세히는 `docs/07_BUSINESS.md` 6절.
