## 1. 한 장 요약 (린 캔버스)
| 칸 | 내용 |
|---|---|
| 문제 | ① '5분만'이 20분을 넘긴다(한 번 보면 평균 21분¹). ② 숏폼은 찾아서 보기보다 **추천·우연으로 빨려 들어가는** 경우가 약 5배 많고, 20대가 가장 심하다². ③ 기존 앱은 막거나(차단) 늦출(마찰) 뿐이고, 그 효과는 약 20일 뒤 정체된다³ |
| 고객 | 만 19~29세 대학생·취준생·사회초년생. 숏폼은 좋아하지만 밤에 못 끊는 사람. 얼리 어답터: 기숙사·자취 대학생, 시험 기간 학생 |
| 해결 | 막지 않고 **말 건다**: 각설탕 르르가 보는 시간만큼 녹으며 가장자리에서 빼꼼 → 메신저형 알림 → 친구가 맡겨 둔 잔소리. 생성형 AI가 **내 기록**으로 '언제·어디서 넘어와' 빠지는지 매주 분석하고, 채팅으로 물으면 근거를 붙여 답한다 |
| 고유 가치 | "내가 왜 자기 전에 못 끊는지, 내 기록으로 알려 주는 친구." 웹 검색 범위에서는 숏폼 감지 + 내 기록 기반 AI 분석 + 보는 순간 도착하는 친구 메시지 + 한국어 캐릭터를 한꺼번에 하는 앱을 찾지 못했다⁴(없다는 증명은 아님) |
| 경쟁 우위 | 맥락·경로 데이터(기기 안에만 저장), 친구 연결망(같이 쓰면 효과가 커짐⁵), 캐릭터 IP(르르) |
| 채널 | 대학 커뮤니티(에브리타임), 인스타·틱톡 숏폼 광고(아이러니를 활용한 캠페인), 친구 초대(잔소리 맡기기 자체가 초대 고리), 대학 상담센터·청년센터 제휴 |
| 수익 | 부분 유료 구독(B2C) + 기관 라이선스(B2B·B2G). 광고·데이터 판매 없음 |
| 비용 | 클라우드 AI 호출(주 1회 리포트 + 채팅), Firebase, 캐릭터·콘텐츠 제작, 마케팅 |
| 핵심 지표 | 기준선 대비 감소율, 알림 뒤 멈춘 비율, 4주 유지율, 친구 연결 수 |

- **시장 크기 (추정)**: 20대 약 567만 명 × 과의존 위험군 29.5~34% ≈ **167만~193만 명**이 1차 고객(SAM). 첫 해 목표는 그중 약 0.5%(8천~1만 명, 반올림해 **약 1만 명**) 가입(SOM). 이 값은 검증된 수요가 아니라 계획값이다. 위험군 비율 29.5%는 20~30대를 합친 값이라 20대만의 비율과 다를 수 있다.
- **정책 공백**: 정부 프로그램(스마트쉼센터 18곳, 2026-08 디지털 디톡스 프로그램)은 대부분 청소년 대상이다. 20대를 직접 겨냥한 것은 서울광역청년센터–서울스마트쉼센터 협약(2025-07) 정도다([벤처스퀘어, 2025-07-17](https://www.venturesquare.net/993909)). 위험군 비율이 높은 20대가 비어 있다.
- **플랫폼의 움직임**: 유튜브가 쇼츠 일일 한도(2025-10)와 보호자 쇼츠 제한(2026-01)을 냈다. 다만 앱 하나 안의 기능이고 사용자가 닫을 수 있다. 앱을 넘나드는 세션·맥락 분석과 친구 기능으로 차별화한다.

## 3. 경쟁과 위치
| 방식 | 대표 앱 | 가격(한국) | 한계 | 사르르 |
|---|---|---|---|---|
| 막기 | Opal, Jomo, 지키자, 눕따, Brick(기기) | Jomo 연 ₩43,000 · 눕따 ₩4,400(1회) · Opal 연 $99.99(미국 가격, 한국 가격 미확인) | 풀어 버리면 끝, 숏폼만 골라 막기 어려움 | 막지 않는다 — '그만'은 언제나 1탭 |
| 늦추기(마찰) | one sec, ScreenZen, ClearSpace, un:short | one sec 월 ₩5,000 / 연 ₩15,000 | 약 20일 뒤 익숙해짐 | 단계가 올라가고, 문구가 매주 바뀌고, 친구 메시지가 섞인다 |
| 숏폼 피드 차단 | StopScroll, Shortstop, Block Scroll | 무료 + 인앱 | 원인 분석 없음 | 언제·어디서 빠지는지 분석 |
| 공부 랭킹 | 열품타 | 월 ₩3,900~5,900 | 숏폼 감지 없음 | 감소율로 공정하게 겨룸(ADR-0005) |
| AI 코치 | Monk, FocusGuard | — | 일반 조언 | 내 기록만 근거로, 숫자는 코드가 셈 |

가격 출처: 각 앱의 한국 앱스토어(2026-11 확인), `docs/research/market.md` 3·5절.

**근거가 말하는 설계** (`docs/research/market.md` 4절)
- one sec 연구(PNAS 2023): 6주 현장 실험(N=280)에서 실제 앱 열기 **57% 감소**. 같은 논문의 사전등록 온라인 실험(N=500)에서는 '그만두기' 선택지가 가장 효과가 컸고, 생각하게 하는 문구만으로는 효과가 없었다([DOI](https://www.pnas.org/doi/10.1073/pnas.2213114120)). → 르르의 말 걸기는 반드시 **쉬운 '그만' 버튼 + 짧은 지연**과 함께 간다.
- 같은 마찰을 반복하면 약 20일 뒤 정체된다(CHI 2024). → 단계 사다리, 매주 새 문구 팩, 친구 잔소리로 새로움을 유지한다.
- 그룹 조건에서만 약 24% 감소, 혼자서는 유의하지 않음(KAIST, CSCW 2015). → 친구 기능은 장식이 아니라 핵심이다.
- 18~29세 무작위 실험: 사용 시간을 줄이자 우울 증상 27% 감소, 하지만 실험이 끝나면 사용량이 원래대로 돌아감(BMC Medicine 2025, [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC11846175/)). → 일회성 캠프보다 계속 곁에 있는 도구가 필요하다(구독의 논리).

## 4. 수익 모델
**B2C 부분 유료 (가격은 제안값, 추정)**
| | 무료 | 사르르 플러스 |
|---|---|---|
| 감지·플로팅 르르·카드 1~4단계·하루 시계 | ✓ | ✓ |
| 주간 리포트(코드가 센 관찰) | ✓ | ✓ |
| AI 주간 분석(가설·전략) | 월 1회 | 매주 |
| 코치 채팅 | 하루 3번 | 하루 30번 |
| 친구 | 3명 | 무제한 + 주간 리그 |
| (P2) 르르 꾸미기(계절 각설탕 등) — 새 몸 그림이 필요해 ADR-0008을 고치는 새 ADR이 있어야 함 | 기본 | 전부 |
- 가격: **월 ₩3,900 / 연 ₩29,000**(연간 플랜 강조, 17일 이상 무료 체험). 국내 자기관리 앱 가격대(월 ₩3,300~5,900, 연 ₩15,000~40,000) 안이다.
- 전환 가정: 건강·피트니스 앱의 35일 결제 전환 중앙값 2.9%, 체험 → 유료 37.7%([RevenueCat SOSA 2026](https://www.revenuecat.com/state-of-subscription-apps-2026/)). AI 앱은 결제자당 매출이 약 41% 높지만 이탈이 30~36% 빠르다(같은 자료).
- 위험: 안드로이드 전용이다. 60일 설치당 매출은 Google Play $0.14로 App Store $0.38보다 낮다([RevenueCat SOSA 2025](https://revenuecat.com/state-of-subscription-apps-2025)). B2B·B2G로 보완한다.
- **원칙**: 광고 없음, 데이터 판매 없음, 원시 기록은 기기 밖으로 안 나감(ADR 계열). 신뢰가 이 앱의 상품이다.

**B2B·B2G (기관 라이선스, 추정)**
| 고객 | 왜 | 무엇을 판다 | 근거 |
|---|---|---|---|

**단위 경제 (추정, 첫 해 1만 명 기준)**: 클라우드 AI는 앱이 화면에 있을 때만, 주 1회 리포트 + 채팅. 사용자당 하루 상한(채팅 30턴, 리포트 재생성 3회, 05 문서 2절)을 두고, 무료 사용자 호출은 기기 안 모델(지원 기기) → 저가 모델 순으로 보낸다. 실제 단가는 출시 시점 Gemini 요금표로 다시 계산한다.

## 6. 지식재산·법
- **이름**: '사르르'는 일반 의태어라 식별력이 약할 수 있고, 식품·디저트 이름으로 많이 쓰인다(쥬씨 '사르르 타르트' 등). 웹에서는 같은 이름의 앱을 찾지 못했지만 KIPRIS는 직접 확인하지 못했다. 출시 전 **9·42·44·41·35류**로 검색하고, 르르 그림과 결합한 표장(로고)으로 출원하는 것을 검토한다. 검색어는 `docs/brand/BRAND.md` 5절.
- **캐릭터 그림**: AI가 기계적으로 만든 산출물은 저작물로 인정되지 않고, 사람이 고르고 고치고 배열한 부분만 등록할 수 있다(문화체육관광부·한국저작권위원회 생성형 AI 저작권 안내서, [법률신문](https://www.lawtimes.co.kr/news/articleViewAmp.html?idxno=209882)). → 제작 기록(프롬프트, 고른 이유, 손본 내역)을 남기고, 상표로 보호한다. 쓴 이미지 생성 서비스의 상업적 이용 약관을 확인한다.
- **개인정보**: 사용 기록은 민감할 수 있다. 원시 기록은 기기 안에만, 클라우드에는 요약만, **만 18세 미만은 이용 불가**(Gemini API 약관, ADR-0009). 무료 등급 AI는 입력이 개선에 쓰일 수 있어 집계만 보내고, 베타 이후에는 유료 등급으로 옮긴다(국외 이전 고지 포함, 04 문서 5절).
- **플랫폼 정책**: 접근성 API는 선택 기능(정밀 모드)으로만 쓰고 고지·동의·Play Console 선언을 지킨다. AI가 다른 앱을 조작하지 않는다(ADR-0001).

## 9. 발표에 쓸 숫자 5개
1. 동영상 이용자의 **91.7%** 가 숏폼을 본다(2025 과의존 실태조사).
2. 청년층 스마트폰 과의존 위험군 **29.5%**, 전체 22.7%보다 높다(같은 조사).
3. 숏폼은 찾아서 보기보다 추천·우연으로 보는 경우가 **약 5배**, 20대가 가장 높다(한국언론진흥재단).
4. 쉬운 '그만' 선택지 하나로 앱 열기 **57% 감소**(PNAS 2023).
5. 친구와 함께일 때만 사용 시간 **24% 감소**(KAIST, CSCW 2015).
