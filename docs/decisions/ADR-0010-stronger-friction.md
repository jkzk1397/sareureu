# ADR-0010 '5분만 더'를 1단계부터 귀찮게 (마찰 사다리 강화)

- 상태: 확정 (2026-11-06, 리드 요청)
- 맥락: PRD 7.2의 사다리는 1단계 '5분만 더'가 버튼 한 번이고, 문장 입력은 3단계에서야 나온다. 리드가 실제로 써 보니 "5분만 더 했을 때 따라서 적는다거나, 어느 정도 귀찮게 해야 한다"는 의견을 냈다. 마찰은 금방 익숙해지므로(PRD 6절 L1) 첫 연장부터 손이 가야 한다.
- 결정: 연장할 때마다 손이 더 가게 한다. '그만'은 모든 단계에서 1탭 그대로다(ADR-0001).

| 단계 | 연장 조건 | 연장 |
|---|---|---|
| 1 | "5분만 더 볼게"를 그대로 따라 쓰기 | 5분 |
| 2 | 이유 칩 고르기 → 숨 고르기 5초 → "알면서도 5분만 더 볼게" 따라 쓰기 (+ 메시지 알림) | 5분 |
| 3 | 숨 고르기 10초 → "지금 멈추면 더 개운한 거 알지만 그래도 5분만 더 볼게" 따라 쓰기 | 5분 |
| 4 이후 | 숨 고르기 15초 → 질문에 5자 이상 답하기 | 3분 |

- 구현: 단계별 숨 고르기는 `core:intervention` `FrictionLadder`, 연장 조건은 `FrictionGate`(순수 함수, 단위 테스트), 문장은 `strings.xml`(`intervention_type_to_extend_l1~l3`). 1단계부터 입력이 있으므로 카드 창은 모든 단계에서 포커스 가능(키보드 입력)하다.
- 결과: 연장 한 번에 드는 시간이 1단계 몇 초 → 4단계 20초 이상으로 늘어난다. 하루 연장 3회 초과 시 다음 세션이 2단계부터 시작하는 규칙은 그대로라, 자주 미루는 날일수록 처음부터 더 귀찮다. 붙여넣기는 막지 않는다(접근성 입력 도구를 막지 않기 위해).
- 바뀌는 문서: PRD 7.2 표.
