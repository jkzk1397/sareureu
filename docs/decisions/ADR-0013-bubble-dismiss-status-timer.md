# ADR-0013 플로팅 르르 숨기기와 상단바 타이머

- 상태: 확정 (2026-11-23, 리드 결정)

## 결정
1. 시청 중 플로팅 르르(버블)를 끌면 화면 아래 가운데에 X 과녁이 뜨고, 거기에 놓으면 **그 세션 동안** 버블이 숨는다. 버블 패널에도 같은 동작('숨기고 상단바 타이머로 보기')을 둔다(끌기를 못 쓰는 사용자용).
2. 숨긴 동안은 상단바 알림 타이머(`PauseNotifier.postBubbleTimer`)가 다음 카드까지 거꾸로 센다. '오늘은 그만'이면 세션 시작부터 센다. 소리·진동 없는 낮은 중요도 알림이다.
3. 타이머가 끝나면 지금처럼 엔진이 카드(멈춤 팝업)를 띄운다. 숨기기는 화면만 바꾸고 개입 규칙(`NudgeEngine`)은 바꾸지 않는다. 새 세션이면 버블이 다시 나온다.
4. 버블은 놓을 때의 속도를 스프링에 그대로 넘겨 관성 있게 가장자리에 붙는다.
5. 권한: `POST_PROMOTED_NOTIFICATIONS`(Android 16+ 일반 권한, 설치 때 자동, 사용자에게 묻지 않음)를 더해 타이머를 상단바 칩으로 요청한다. 사용자가 설정에서 끄거나 지원하지 않는 기기면 보통 알림의 타이머로 보인다(대체 흐름). 알림 권한이 없으면 타이머 없이 카드만 뜬다.

## 이유
버블이 영상을 가린다는 불편이 있다. 완전히 끄면 '볼 때 말 걸어 주는 친구'가 사라지므로, 시간은 상단바에서 계속 보이게 하고 약속한 시점의 개입은 그대로 둔다.
