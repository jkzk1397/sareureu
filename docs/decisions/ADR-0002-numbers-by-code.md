# ADR-0002 숫자는 코드가, 말은 AI가

- 상태: 확정 (2026-11-03)
- 결정: 모든 통계·순위·감소율·위험 시간대는 `core:insights`의 순수 함수가 계산한다. 생성 문구(리포트, 문구 팩, 질문, 초안)에서 AI는 숫자 대신 자리표시자(`{min}`, `{reduction}` 등)를 쓰고 코드가 채운다. 채팅 답변의 숫자는 그 턴의 도구 결과와 일치해야 한다. 모든 AI 출력은 스키마 + 검증기를 통과해야 화면에 나온다.
- 이유: LLM은 계산을 틀리고 데이터에 없는 원인을 지어낸다. 숫자가 틀리면 신뢰가 무너진다.
- 결과: `05_AI_SPEC.md` 4절 숫자 정책, 검증기 단위 테스트, 평가 하네스의 "숫자 위반 0건" 합격선.
