# ADR-0001 막지 않고 말 건다

- 상태: 확정 (2026-11-03)
- 결정: 다른 앱을 강제로 닫거나 가리지 않는다. 개입은 오버레이 카드·플로팅 캐릭터·알림뿐이고, '그만 볼래'는 모든 단계에서 한 번 탭이다. '그만'은 홈 화면 인텐트(`Intent.ACTION_MAIN` + `CATEGORY_HOME`)로 보낸다. 접근성 API로 다른 앱을 조작(뒤로 가기, 클릭, 스크롤)하지 않는다.
- 이유: (1) 차단·지연은 2~3주면 익숙해지고 우회된다. (2) Google Play 접근성 정책은 앱이 스스로 행동을 계획·실행하는 사용을 금지한다. (3) 우리 차별점은 '맥락을 아는 대화'다.
- 결과: `core:intervention`은 규칙 엔진으로만 동작하고 `core:ai`에 의존하지 않는다. '5분만 더' 마찰은 단계별로 올라가되 끝까지 '그만'은 쉽다.
