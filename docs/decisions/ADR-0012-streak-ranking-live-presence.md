# ADR-0012 친구: 목표 지킴 연속 일수 랭킹, 지금 시청 중 표시, 실시간 잔소리, QR 초대

- 상태: 확정 (2026-11-23, 리드 결정)
- 대체: ADR-0005의 (1) 친구 랭킹 기준, (3) 상위 3 + 나만 공개, (5) 공유 숫자 범위. 주간 리그(P1)·기록률 80% 규칙(기준선·감소율 계산)은 그대로다.

## 결정
1. **친구 랭킹 = 목표 이하 연속 일수.** 각자 프로필의 하루 목표(`dailyGoalMinutes`) 이하로 본 날이 어제부터 거꾸로 며칠 이어지는지(`core:insights.GoalStreak`). 새벽 4시 경계, 첫 기록 전 날은 세지 않고, 오늘 이미 목표를 넘겼으면 0. 계산은 앱이 하고 서버는 `streakDays` 숫자만 저장한다(ADR-0002).
2. **모두 보인다(듀오링고처럼).** 내가 연결한 친구 + 나를 연속 일수 순서로 전부 보여 준다(`StreakRanking`). 같은 일수면 같은 순위. 1위 금 왕관, 2·3위 은·동 메달(아이콘 안에 숫자), 4위부터 숫자만.
3. **지금 시청 중(초록 점).** 공유에 동의했고 실제로 숏폼 화면에 있는 동안만 앱이 2초마다 `PUT /api/v1/presence {"watching":true}`를 보내고, 멈추면 `false`를 한 번 보낸다. 서버는 마지막 신호 시각만 남기고 **최근 5초 안 신호**가 있으면 친구 목록에 `watching: true`. 앱·영상·시간은 보내지 않는다.
4. **잔소리는 시청 중인 친구에게만, 바로 알림.** 친구 목록의 말풍선은 시청 중인 친구에게만 켜진다. 보내면(40자, 금지 표현 검사) 서버가 받는 사람의 다음 시청 신호 응답에 실어 주고, 받는 앱이 '보낸 사람 이름 + 글'을 메시지 알림으로 띄운다(`FriendPokeAlert`). FCM은 쓰지 않는다(새 의존성·서버 비밀키 없음). 서버는 시청 중이 아니면 `409 not_watching`.
5. **QR 초대.** 초대 코드에 QR(`https://<친구 서버>/invite/{코드}`)을 더한다. 서버 페이지가 `intent://` 주소로 앱(`sareureu://invite/{코드}`)을 열고, 앱이 없으면 브라우저가 설치 파일(APK, `APK_URL`)로 간다. 앱은 친구 탭을 열고 그 코드로 바로 연결한다(동의 전이면 동의 후). QR 생성은 zxing `core` 3.5.4(리드 승인).
6. **동의 버전 2.** 공유 항목이 늘었으므로 `consentVersion` 2로 올린다. 버전 1로 동의한 사람은 친구 탭에서 새 내용으로 다시 동의해야 한다. 서버는 1·2를 모두 받지만 시청 중 신호는 2부터.

## 이유
- 팀이 원하는 경쟁 방식은 "누가 목표를 오래 지켰나"다. 절대 시간이 아니라 **각자 정한 목표** 대비라 원래 많이 보던 사람도 이길 수 있다(ADR-0005의 공정성 취지 유지).
- 시청 중 표시와 실시간 잔소리는 "볼 때 말 걸어 주는 친구"라는 앱의 핵심을 친구 사이로 넓힌다. 받는 사람은 그 순간 숏폼을 보고 있으므로 앱이 이미 깨어 있고, 신호 응답으로 전달하면 몇 초 안에 도착한다.

## 감수하는 것
- 꼴찌가 보인다: 친구는 서로 동의한 사이(초대 코드·QR)뿐이고, 숫자는 연속 일수(시청 시간 아님)라 수치심을 줄인다. 차단·연결 끊기는 그대로.
- 친구가 "지금 숏폼을 보는 중"을 알게 된다: 동의 화면에 명시하고(버전 2), 철회하면 서버의 시청 신호 행도 지워진다.
- 시청 중 2초 신호는 D1 쓰기를 늘린다(시청 1시간당 사용자 1명 약 1,800번). 무료 한도(하루 10만 쓰기)에서 소규모 시연에는 충분하다. 사용자가 늘면 간격을 늘리고 서버 판정 창을 같이 늘린다.
- 연속 일수는 세션 보관 기간(90일)까지만 셀 수 있다.
- 앱이 강제 종료된 상태에서는 잔소리 알림을 못 받는다(받는 사람이 시청 중일 때만 보낼 수 있으므로 감지 서비스가 살아 있는 경우가 대부분). 놓친 것은 서버에 남아 기존 받기(`GET /pokes`)로 나중에 받는다.

## 결과
- 서버: `0006_streak_presence.sql`(`standing.streak_days`, `presence`), `presence.mjs`, `invite-page.mjs`, 친구 목록에 `streakDays`·`watching`.
- 앱: `core:insights.GoalStreak`, `core:social`(`StreakRanking`, `FriendPresence`, `InviteLinks`, `InviteLinkInbox`, 동의 버전 2), `core:data.FriendPokeAlert`(구현 `core:intervention`), `core:designsystem` 색 토큰 `streak`·`rankGold`·`rankSilver`·`rankBronze`, `feature:friends` 친구 목록·랭킹·잔소리 창·QR, `app` 딥링크.
