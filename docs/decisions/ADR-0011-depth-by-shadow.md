# ADR-0011 카드 깊이는 테두리 대신 옅은 그림자로, 누르기·펼치기에 짧은 움직임

- 상태: 제안 (2026-11-16, 리드 요청 — PR에서 승인받는다)
- 맥락: 06 문서 4절은 "그림자 대신 `line` 1dp 테두리"로 정했다. 실제 폰에서 보니 크림색 바탕 위 흰 카드가 회색 선으로만 갈려 납작하고, 카드 안 상자(근거 문장, 요약 한 줄)의 모서리가 카드 모서리와 나란하지 않았다. 펼치는 곳(자세히, 근거, 설정 묶음)은 눌러도 내용이 툭 튀어나와 어디가 열렸는지 놓치기 쉬웠다. 리드가 jakub.kr의 "make-interfaces-feel-better" 규칙으로 다듬어 달라고 했다.
- 결정:
  1. **깊이는 그림자, 구조는 테두리.** 바탕 위에 뜬 표면(카드·말풍선·설정 묶음)은 `Modifier.pauseSurface`: 라이트는 검정 6% 테두리 한 겹 + 그림자 두 겹(검정 6%·4%), 다크는 흰색 8% 테두리 한 겹(어두운 바탕에서는 그림자가 안 보인다). 구분선, 선택 표시(고른 친구, 보는 중 카드의 라임 테두리), 칸 경계(히트맵·챌린지)는 테두리 그대로.
  2. **겹친 모서리는 동심원으로.** 바깥 반지름 = 안쪽 반지름 + 여백. `PauseCard`(28dp, 여백 20dp) 안 상자는 새 토큰 `shapes.nested` 8dp, 여백 16dp인 곳(설정 묶음, 말풍선) 안은 `shapes.small` 12dp.
  3. **제목 줄바꿈은 고르게.** `display`·`headline`·`title`은 `LineBreak.Heading`(줄 길이 균형) + 어절 단위. 본문은 그대로.
  4. **바뀌는 숫자는 고정폭.** `StatHero` 값, 보는 중 경과 분, 숨 고르기 초, 알림 기준 분 등은 `tnum`.
  5. **누르면 0.96으로 살짝 작아진다**(`Modifier.pressScale`, 120ms). 주 버튼·알약·누르는 카드.
  6. **펼치기·접기는 짧게 움직인다**(`Reveal`: 펼침 200ms, 접힘 150ms, ease-out, 도중에 되돌릴 수 있음). 움직임만으로 알리지 않고 ▾▴ 글자를 함께 바꾼다.
  - 시스템 '애니메이션 제거'가 켜져 있으면 5·6은 바로 바뀐다(4절 규칙 그대로).
- 하지 않은 것: 웹 전용 규칙(`will-change`, `transition: all`, 글꼴 스무딩), 아이콘 획 두께 통일(그림 파일이라 R5가 따로 본다).
- 바뀌는 문서: 06 문서 4절.
