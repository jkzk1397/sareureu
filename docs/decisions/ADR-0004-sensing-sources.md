# ADR-0004 감지 소스 세 가지를 같은 인터페이스로

- 상태: 확정 (2026-11-03)
- 결정: `core:sensing`에 `ForegroundSource` 인터페이스를 두고 구현 세 개를 갈아 끼운다.
  1. `UsageStatsSource`(기본): 포그라운드 서비스가 화면이 켜져 있을 때 `UsageStatsManager.queryEvents`를 짧은 주기로 조회해 지금 앞에 있는 앱을 판단. 앱 단위. 권한: 사용 기록 접근.
  2. `AccessibilitySource`(선택 '정밀 모드'): 창 전환 이벤트로 즉시 판단 + 쇼츠·릴스 화면 판별 + 스크롤·클릭 횟수. 판별 규칙은 `assets/surface_rules.json`(원격 설정으로 갱신 가능)에 두고 view ID 하나에 의존하지 않는다.
  3. `DemoEventSource`: 시연용 가상 이벤트, 시계 배속.
- 이유: 접근성은 정확하지만 Play 고지·선언 부담과 앱 업데이트에 따른 깨짐이 있다. 앱 단위는 쇼츠만 못 가르지만 안정적이다. 시연은 권한 없이 돌아야 한다.
- 결과: 세션 생성(`SessionTracker`), 맥락 분류, 경로 계산은 소스와 무관하게 같은 코드. 앱 단위 모드에서는 화면에 "유튜브 전체"라고 정직하게 표시한다.
