# ADR-0005 공정한 감소율 랭킹과 주간 리그

- 상태: 확정 (2026-11-03)
- 원안: 전체 사용자 / 친구의 시청 시간 감소율 랭킹.
- 결정: (1) 친구 랭킹은 서로 동의한 친구끼리, **각자 기준선(처음 7일, 기록률 80% 이상인 날) 대비 감소율**로 매긴다. (2) 기록률 80% 미만인 날은 계산에서 뺀다. 유효한 날이 5일 미만이면 "측정 중". (3) 상위 3명 + 나만 보여 주고 꼴찌는 드러내지 않는다. (4) 전체 사용자는 순위표 대신 기준선이 비슷한 20~30명 그룹의 **주간 리그**(P1). (5) 공유하는 숫자는 감소율과 기록률뿐이다.
- 이유: 절대 시간 순위는 원래 적게 보는 사람만 이긴다. 감지를 끄면 감소율이 오르는 조작을 막아야 한다. 공개적인 최하위 표시는 수치심을 준다.
- 결과: `core:insights.Baseline`, `ReductionRate`, `Coverage` 계산과 단위 테스트. Firestore에는 `publicDaily`만 친구에게 노출.
