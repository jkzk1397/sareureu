# 01. 제품 정의서 (PRD) — 사르르

> 상태: v1.1 (2026-11-05, 이름·캐릭터 확정) · 담당: R1 · 바꿀 때는 ADR을 함께 쓴다.
> 근거 자료와 출처는 `docs/02_RESEARCH.md`, 구조는 `docs/03_ARCHITECTURE.md`.

## 1. 한 줄 정의
**숏폼에 녹아든 시간, 말 걸어 주는 친구 — 사르르.** 캐릭터는 각설탕 **르르**: 오늘 본 만큼 조금씩 녹고, 새벽 4시에 새 각설탕이 된다. 내가 언제·어디서 넘어와·얼마나 숏폼에 빠지는지 자동으로 분석하고, 그 패턴에 맞는 순간에 캐릭터·메신저형 알림·채팅으로 말을 건다. 앱을 막지 않는다. 언제나 내가 고른다.

## 2. 문제
- 숏폼은 끝이 없고 다음 영상이 자동으로 이어져, "5분만"이 금방 20분을 넘긴다(한 번 보기 시작하면 평균 21분, `02_RESEARCH.md` 1절).
- 기존 해결책은 둘 중 하나다. **막기**(차단·시간 제한)는 금방 풀어 버리고, **늦추기**(숨쉬기·대기 화면)는 2~3주면 익숙해진다.
- 유튜브·인스타의 자체 타이머는 앱 하나 단위이고 한 번 탭하면 닫힌다. 쇼츠 → 릴스 → 틱톡으로 넘어가면 아무도 모른다.
- 무엇보다 **내가 왜 이 시간에 이걸 열었는지**(출근길이라서, 밥 먹으면서, 카톡 보다가, 자기 전에)를 알려 주는 도구가 없다.

## 3. 타깃
1차: 만 19~29세 숏폼 이용자(대학생·취준생·사회초년생). 2차: 만 30세 이상. **만 18세 미만은 이용할 수 없다**(ADR-0009): Gemini API 약관이 만 18세 이상을 요구하고 18세 미만이 쓸 가능성이 높은 서비스에서의 사용을 금지하며, 만 14세 미만 법정대리인 동의 절차도 피한다. Play 타깃 연령도 18세 이상.

| 페르소나 | 하루 | 숏폼에 빠지는 순간 | 원하는 것 |
|---|---|---|---|
| 서연, 22, 대학생 | 9시 수업, 통학 50분, 새벽 1시 취침 | 과제 막힐 때, 자기 전 침대 | 밤에 덜 보고 일찍 자기 |
| 민재, 27, 직장인 | 지하철 출퇴근 각 40분, 점심 1시간 | 출근길, 점심 먹으며, 퇴근 후 소파 | 출퇴근길 시간을 좀 더 쓸모 있게 |
| 하린, 25, 취준생 | 불규칙, 스터디카페 | 공부 중 틈새, 카톡 알림 뒤 | 공부 흐름 안 끊기기 |

## 4. 차별점 (한 문장씩)
1. **맥락을 안다**: 시각만 보는 타이머가 아니라 하루 리듬으로 "출근길·식사·자기 전"을 구분해 맥락마다 다르게 말한다.
2. **경로를 안다**: 카톡 → 쇼츠, 잠금 해제 → 릴스처럼 어디서 빨려 들어가는지 보여 준다.
3. **친구처럼 말 건다**: 막는 화면이 아니라 캐릭터와 메신저형 알림. 진짜 친구가 맡겨 둔 '잔소리'가 내가 숏폼 볼 때 도착한다.
4. **AI는 근거를 댄다**: 숫자는 코드가 세고, AI는 그 숫자를 근거로 가설을 말한 뒤 "맞아?"라고 묻는다.
5. **공정한 경쟁**: 절대 시간이 아니라 내 기준선 대비 감소율로 친구와 겨룬다.

## 5. 제품 원칙
1. **막지 않고 말 건다.** '그만'은 언제나 한 번 탭. 다른 앱을 강제로 닫지 않는다.
2. **숫자는 코드, 말은 AI.** AI 문장에는 근거가 붙고, 검증을 통과한 것만 보인다.
3. **장난은 OK, 수치심은 NO.** 놀림·비하·진단(중독 등) 표현 금지.
4. **내 기록은 내 폰에.** 원시 기록은 기기 밖으로 나가지 않는다. 공유는 동의한 합계만.
5. **추정은 추정이라고 말한다.** "식사 중"처럼 기기가 알 수 없는 것은 확인 질문으로 보정한다.

## 7. 핵심 흐름

### 7.1 온보딩 (3분 이내)
5화면(2026-11 개편, 깔고 나서 지치지 않게): ① **시작** 연령대(만 18세 미만이면 안내, ADR-0009) + 약관·개인정보 동의 ② **나** 별명·신분·평일 자는 시간(주말 +1시간, 기상·통학·수업/업무·식사는 신분별 기본값, 설정 › 하루 리듬에서 고침) ③ **목표** 목표 칩 + 하루 목표 분(관심사·말투는 기본값, 설정에서 바꿈) ④ **권한** 사용 기록(필수)·알림·다른 앱 위 표시를 한 화면에 세 줄로 ⑤ **AI** "AI 친구 쓰기 / 나중에"(국외 이전 한 줄) → 시작(프로필 저장 + 감지 켜기). 추적 앱은 기본값(설정 › 추적 앱), 배터리 안내는 설정 › 감지. 화면마다 처음 보이는 글은 두 문장 이하, 고지 전문은 "자세히"로 접는다.
- 권한마다 **자기 줄에서** 무엇을 왜 쓰는지 한 문장으로 고지하고(전문은 "자세히"), 사용자가 그 줄의 [허용]을 직접 눌러야 설정을 연다. 권한끼리 한 버튼으로 묶지 않는다. (선택) 정밀 모드 접근성은 만들 때 별도 고지 화면(Play 고지 요건).
- 어떤 권한을 거절해도 앱은 돈다: 사용 기록 거절 → 시연 모드 안내, 오버레이 거절 → 알림으로 대체, 접근성 거절 → 앱 단위 측정.

### 7.2 실시간 개입 사다리
`T` = 지금 맥락의 임계값(기본: 밤 = 자기 전·한밤중 10분, 나머지 15분). 사용자는 설정에서 **평소**·**밤** 두 줄(`ThresholdGroup`)만 1~60분, 1분 단위로 바꾼다. 줄 하나를 바꾸면 그 묶음의 맥락 전부에 같은 값이 저장된다(저장은 맥락별 그대로). 주간 리포트에서 AI가 "자기 전은 10분으로 낮출까?"처럼 제안하면 수락할 때만 그 맥락이 속한 묶음 전체가 바뀐다.

| 시점 | 무엇이 뜨나 | 사용자 선택 |
|---|---|---|
| 숏폼 시작 | 플로팅 캐릭터가 가장자리에 살짝 등장, 경과 시간 링 | 무시 / 탭해서 미니 패널 |
| `T` | **카드 1단계**: "쇼츠 15분째" + 맥락 문구(예: "자기 전 15분은 보통 40분이 되더라") | [그만 볼래] / "5분만 더 볼게"를 따라 써야 연장(ADR-0010) |
| `T+5` | **메시지 알림** 헤드업 알림(AI 친구 또는 친구의 잔소리) + **카드 2단계**: "왜 더 보고 싶어?" 칩(심심해서·피곤해서·할 일 미루는 중·재밌어서·그냥) → 칩에 맞는 답 문구 | [그만] / 칩 → 5초 숨 고르기 → "알면서도 5분만 더 볼게" 입력 후 연장 |
| `T+10` | **카드 3단계**: 10초 숨 고르기 카운트다운 뒤, 더 긴 문장("지금 멈추면 더 개운한 거 알지만 그래도 5분만 더 볼게")을 직접 입력해야 연장 | [그만] / 입력 후 연장 |
| `T+15` 이후 | **카드 4단계**: 연장은 3분으로 줄고, 15초 숨 고르기 뒤 미리 만든 질문 하나에 5자 이상 답해야 연장 | [그만] / 답 후 연장 |

- '그만'은 모든 단계에서 1탭 → 홈 화면으로 보내고(일반 인텐트, 접근성 조작 아님) 캐릭터가 칭찬 한마디. `stopRate`에 반영.
- 하루에 연장을 3번 넘게 누른 날은 다음 세션이 2단계부터 시작(누를수록 어려워지게).
- 2단계부터 "오늘은 그만 알려줘" 가능(그날만, 기록에 남음, 캐릭터는 탓하지 않음).
- 세션 종료: 숏폼 앱을 60초 넘게 떠나거나 화면이 꺼지면. 쇼츠 → 릴스처럼 숏폼끼리 넘어가면 **같은 세션**(도미노도 잡는다).

### 7.3 예약·미리 알림
- 예약 알림: 사용자가 고른 시각(최대 3개). 기본 제안 "취침 30분 전 결산".
- 위험 시간대 미리 알림: 지난 2주에 숏폼이 가장 길었던 '요일×시간' 칸 10분 전에 하루 1번. 문구는 문구 팩에서.
- 정확한 알람 권한(`SCHEDULE_EXACT_ALARM`)은 쓰지 않는다. 몇 분 오차는 괜찮다.

### 7.4 리포트와 AI 친구 채팅
- **오늘 탭**: **하루 시계**(24시간 다이얼, 위가 0시(자정)·위 반이 밤, 시간대별 꽃잎을 맥락 색으로, 가운데 오늘 합계, 지금 위치, 위험 시간대 점선), 어제 대비, 지금 상태(보는 중이면 경과), 캐릭터 한마디, 받은 잔소리, 내 계획.
- **리포트 탭**(주간, 일요일 저녁 생성 알림): **일주일 시계**(같은 다이얼에 일주일 시간대별 합계, "시계 / 표" 토글), 코드가 계산한 관찰(맥락별 합계, 위험 시간대, 진입·이탈 상위, 세션 길이, 연장·멈춤, 기록률, 또래 비교) → AI 해석(가설 최대 3개, 각 근거 칩 + 확신도) → "맞아 / 반쯤 / 아니야, 사실은…" → 맥락별 전략 카드 2~3개 중 고르기 → 다음 주 임계값·미리 알림 제안 수락 → **숏폼 유형 카드**(공유용).
- **코치 탭**: AI 친구와의 대화방. 메시지 알림이 여기 쌓인다. "나 언제 제일 많이 봐?", "왜 자기 전에 못 끊을까?", "출근길에 뭐 하면 좋아?" 같은 추천 질문 칩. 답에는 근거 칩(세션·통계)이 붙는다.

### 7.5 친구
- 친구 추가(초대 코드·링크), 서로 동의해야 연결.
- **잔소리**: 친구에게 메시지를 맡겨 두면, 그 친구가 숏폼을 오래 볼 때(2단계) 메시지 알림으로 도착한다. AI가 초안을 써 준다. 보낸 사람은 전달 여부를 모른다(받는 사람이 "전달되면 알려 주기"를 켠 경우만 앎).
- **친구 랭킹**: 주간 감소율. 상위 3명 + 나. 동의한 친구만, 숫자는 감소율과 기록률만 공유(시청 시간·맥락·앱은 공유 안 함).
- **주간 리그**(P1): 기준선이 비슷한 사람끼리 그룹, 상위는 승급.
- **함께 챌린지**: 예) "이번 주 한밤중 0분" — 팀원 달성 칸이 채워진다.

## 8. 맥락 분류 규칙과 맞춤 피드백 (요약, 자세히는 03·05 문서)
| 맥락 | 판단 기준(우선순위 순) | 기본 임계 | 피드백 예시 |
|---|---|---|---|
| 한밤중 `LATE_NIGHT` | 취침 시각 + 30분 ~ 기상 시각 | 10분 | "깼구나. 폰 대신 물 한 잔?" |
| 자기 전 `PRE_SLEEP` | 취침 시각 −60분 ~ +30분, 또는 21시 이후 충전 중 | 10분 | 침대 밖 충전, 잠들 오디오로 바꾸기 |
| 기상 직후 `WAKE_UP` | 그날 첫 잠금 해제 후 45분 이내(기상 시각 ±2시간) | 15분 | 알람 끄고 숏폼 앱 없는 홈 화면 |
| 이동 `COMMUTE` | 평일 통학·출퇴근 시간대(+이어폰 연결이면 확신도↑) | 15분 | 끝이 있는 콘텐츠(저장한 글·오디오), 내릴 역에서 멈춤 |
| 식사 `MEAL` | 식사 시간대(확신도 낮음 → 확인 질문) | 15분 | 밥 먹는 동안 폰 뒤집기 |
| 수업·업무 중 `CLASS_WORK` | 평일 수업/근무 시간대 | 15분 | 막힌 일 '다음 한 줄' 메모 후 돌아가기 |
| 쉬는 시간 `BREAK` | 위에 없는 9~21시 | 15분 | 볼 것 정하고 보기, 끝나면 일어나기 |
| 기타 `OTHER` | 나머지 | 15분 | — |

## 9. 지표 정의
| 지표 | 정의 | 쓰는 곳 |
|---|---|---|
| 숏폼 시간 | 추적 앱 숏폼 세션 길이 합(정밀 모드가 아니면 "앱 전체"라고 표시) | 오늘·리포트 |
| 기준선 `Baseline` | 처음 7일(기록률 80% 이상인 날) 하루 평균 | 감소율 |
| 감소율 `reductionRate` | (기준선 − 이번 주 하루 평균) / 기준선. 유효한 날 5일 미만이면 "측정 중" | 랭킹·리포트 |
| 멈춘 비율 `stopRate` | 카드가 뜬 세션 중 '그만'을 누르고 60초 안에 숏폼을 떠난 비율 | 리포트·북극성 |
| 기록률 `coverage` | 화면이 켜진 시간 중 감지가 살아 있던 비율 | 데이터 신뢰도·조작 방지 |
| 위험 시간대 `RiskWindow` | 지난 14일 요일×시간 칸 중 숏폼 시간 상위 3칸(최소 3일 이상 등장) | 미리 알림 |

**북극성 지표**: 주간 `stopRate` × 위험 맥락(자기 전·한밤중) 시간 감소. 총 시간 감소는 보조 지표.

## 11. 시연 시나리오 (5분)
1. 설정 > 시연 모드 켜기(2주치 가상 기록, 가상 친구 3명).
2. 오늘 탭(목업 01): 하루 시계 + "어제보다 23분 줄었어" + "밤 10시 반부터가 제일 위험해" 카드.
3. 가상 숏폼 재생 버튼 → 플로팅 캐릭터 등장 → (시연 시계 60배속) 10분(밤 기준) → 카드 1단계 → '5분만 더' → 메시지 알림 헤드업("민지: 너 아직도 쇼츠 봐? 내일 1교시야") → 2단계 이유 칩 → 3단계 입력 마찰 → '그만' → 칭찬.
4. 리포트 탭: 맥락 링, 진입·이탈 흐름(메신저 → 쇼츠 → 화면 끔), 히트맵, AI 가설 3개와 근거 칩 → "반쯤 맞아" → 전략 카드 선택 → 유형 카드.
5. 코치 탭: "나 왜 자기 전에 못 끊어?" → 함수 호출로 기록 조회 → 근거 칩이 달린 답 + 전략 제안.
6. 친구 탭: 감소율 랭킹, 친구에게 잔소리 맡기기(AI 초안).
7. 설정 > AI 감사 로그: 보낸 요약·받은 답·검증 결과.

## 12. 수용 기준 (MVP)
- 권한 없이도 시연 모드로 11절 시나리오 전체가 끊김 없이 돈다.
- 실기기(안드로이드 10 이상)에서 유튜브를 15분 넘게 보면 카드가 15분 ±30초 안에 뜬다(앱 단위 모드).
- '그만'은 모든 단계에서 한 번 탭으로 홈 화면에 간다.
- 같은 날 연장 3회 초과 후 다음 세션은 2단계부터 시작한다.
- 맥락 분류 단위 테스트: 8개 맥락 경계값 케이스 전부 통과.
- 진입·이탈 계산 단위 테스트: 잠금 해제·홈·메신저·도미노·화면 끔 케이스 통과.
- AI 출력은 검증기 통과분만 보이고, 실패 시 모의 결과 + 감사 로그 기록.
- 평가 하네스: 모의 제공자로 전 케이스 실행, 리포트(CSV/Markdown) 생성.
- 라이트·다크 모든 화면 대비 WCAG AA(본문 4.5:1).
- 설정에서 "모든 기록 삭제"를 누르면 로컬 DB·DataStore·캐시가 비워진다.
